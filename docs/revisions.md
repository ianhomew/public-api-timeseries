# 經複核修正的宣稱

回上層：[README](../README.md)

本檔記錄本專案曾經寫出、後經複核被**推翻或收斂**的宣稱。保留紀錄是為了可稽核，
不是為了說服。以下只陳述事實。

## 1. `mcp_registry` 的獨佔性不成立（2026-08-27）

**原宣稱**：MCP 官方註冊表的 `status` / `statusChangedAt` 無歷史版本，值得逐日快照。

**複核發現**：

- 單日快照本身即含同一 server 的多個版本（例如 `ac.inference.sh/mcp` 有 1.0.0、1.0.1、2.0.0、2.0.1）。
- 官方 API 支援 `updated_since` 參數，可回溯查詢。
- 抽樣 120 筆，全部在線，無刪除紀錄。
- 該來源佔當日抓取時間 946.9 秒，約為總時間的 93%。

**處置**：2026-08-27 起停止抓取。2026-08-26 已抓的 82,612 筆保留不刪。

## 2. 金管會內頁「Wayback 存檔 0 份」為誤判（2026-08-27）

**原宣稱**：金管會全站內頁在 Internet Archive 的存檔數為 0 份。

**錯誤原因**：查詢時用的是**網域層**統計，而非該欄目的**精確 URL 樣式**。

**修正後事實**：`fsc_clarification` 的 50 篇中，**49 篇已存在於 Wayback**。
但抽樣的中位擷取數僅 **1 次**，其中 56% 的篇目無法用 Wayback 偵測發布後的改寫。

**價值主張收斂**：從「唯一副本」改為「**高頻改寫偵測**」。

## 3. `vast_gpu` 並非固定 64 筆（2026-08-27）

**原宣稱**：vast.ai 免金鑰端點固定回傳 64 筆，這是認證限制。

**修正後事實**：64 筆是**未帶 API 金鑰**時的結果（2026-08-26 快照）。
2026-08-27 起改用金鑰認證後，同一端點回傳 **512 筆**。
快照內的 `_authenticated` 欄位記錄該次抓取是否帶金鑰。

跨日比較筆數時必須先看 `_authenticated`，否則會把認證狀態的差異誤讀為市場變化。

## 4. 每日資料量從約 13 MB 降為約 6.6 MB（2026-08-27）

`mcp_registry` 停抓後，`track-crypto` 每日壓縮後合計約 6.6 MB
（x402 6,045,267 B + cex 407,121 B + vast 174,956 B）。舊文件寫的 13 MB 已不適用。

## 5. `ts` / `tsdiff` 指令不存在（2026-08-27）

舊文件提到用 `ts` 與 `tsdiff` 檢視資料。VPS 上並未安裝這兩個指令。
實際可用的是 `scripts/explore.py`，用法見 [data-format.md](data-format.md)。

## 6. `cex_symbols` 為 7 家交易所，不是 10 家

`snap_crypto.py` 的函式註解寫「十家 CEX」，與實際端點清單不符。
實際為 7 家：bybit、okx、bitget、htx、gateio、kucoin、mexc。Binance 因 robots.txt 排除。
